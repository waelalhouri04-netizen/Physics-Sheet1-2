Basic Quantities & Dimensional Analysis

🔷 الكميات الأساسية — Basic Quantities

The three fundamental dimensions in mechanics

البُعد هو طبيعة الكمية الفيزيائية — فهو يصف ماهية الشيء لا قيمته العددية. يُرمز للأبعاد بأقواس مربعة.

Dimension denotes the physical nature of a quantity, written in square brackets.

[L]
الطول

SI unit: meter (m)
[M]

SI unit: kilogram (kg)
[T]

⚠️ ملاحظة: كثير من الكميات الفيزيائية تكون لا بُعدية (Dimensionless) مثل: الأعداد النقية، نسبة كميتين متشابهتين، الزوايا، وثوابت مثل π.

🔍 كيف نشتق الأبعاد — How to Derive Dimensions

Step-by-step derivation of common quantities

① السرعة (Velocity)

v = displacement / time  ⟹  [v] = L / T = [L T⁻¹]

② التسارع (Acceleration)

a = Δv / Δt  ⟹  [a] = (L T⁻¹) / T = [L T⁻²]

③ القوة (Force): F = ma

[F] = [M][LT⁻²] = [M L T⁻²]

④ الضغط (Pressure): P = F/A

[P] = [M L T⁻²] / [L²] = [M L⁻¹ T⁻²]

⑤ الطاقة (Energy): E = F × d

[E] = [M L T⁻²][L] = [M L² T⁻²]

⚙️ استخدامات التحليل البعدي — Uses of Dimensional Analysis

3 main applications you must know

  • أ) التحقق من صحة المعادلة: إذا كانت أبعاد الطرفين متساوية → المعادلة صحيحة بُعدياً (لكن ليس بالضرورة صحيحة فيزيائياً!)
    Check equation validity — dimensional match is necessary but not sufficient.
  • ب) اشتقاق معادلة: يمكن إيجاد العلاقة بين الكميات بدون تجربة عن طريق مطابقة الأبعاد.
    Derive formulas by matching dimensions on both sides.
  • ج) إيجاد وحدات الكميات المشتقة: تحديد وحدة أي كمية من الصيغة الرياضية لها.
    Find the units of a derived quantity from its defining equation.
مثال على التحقق: هل المعادلة d = vt² صحيحة؟
الطرف الأيسر: [d] = L  |  الطرف الأيمن: [vt²] = (L/T)×T² = L·T ≠ L
→ الأبعاد لا تتطابق ∴ المعادلة خاطئة ✗

🕰️ مثال كلاسيكي — البندول البسيط

Pendulum period: use dimensional analysis to find the formula

فترة البندول P تعتمد على الطول d والتسارع الجاذبي g. أي صيغة صحيحة؟

Pendulum — Which formula is correct?
P = 2π √(d/g)  |  [P] = √(L / LT⁻²) = √(T²) = T ✓

Vectors & Vector Operations

⚖️ الكميات السعرية والكميات المتجهة

Scalar vs Vector Quantities

📦 الكمية السعرية (Scalar)

لها مقدار فقط بدون اتجاه

Has magnitude only — no direction

أمثلة: الكتلة، الطاقة، درجة الحرارة، الزمن، السرعة الاتجاهية الإجمالية، الشحنة الكهربائية

➡️ الكمية المتجهة (Vector)

لها مقدار واتجاه معاً

Has both magnitude AND direction

أمثلة: الإزاحة، السرعة الاتجاهية (Velocity)، التسارع، القوة، الشدة الكهربائية

Vector components and notation in 3D space

يُمثَّل المتجه في الفضاء الثلاثي بواسطة مركباته على المحاور الثلاثة:

A⃗ = Aₓ î + A_y ĵ + A_z k̂

مركبات المتجه — Vector Components
Aₓ = |A| cos θ   |   Aᵧ = |A| sin θ

θ = tan⁻¹(Aᵧ / Aₓ)

➕ جمع المتجهات — Vector Addition

Triangle Law & Component Method

يمكن جمع المتجهات بطريقتين رئيسيتين:

① قانون المثلث (Graphical / Triangle Law)

ضع ذيل الثاني عند رأس الأول، المحصلة هي الضلع الثالث.

R = √(A² + B² + 2AB cosθ)
tan β = (B sinθ) / (A + B cosθ)

② طريقة المركبات (Component Method)

R⃗ = (Aₓ+Bₓ)î + (Aᵧ+Bᵧ)ĵ + (A_z+B_z)k̂

|R⃗| = √(Rₓ² + Rᵧ² + R_z²)
Triangle Law — قانون المثلث

✖️ ضرب المتجهات — Vector Multiplication

Dot product (scalar) and Cross product (vector)

① الضرب النقطي (Dot Product) → نتيجته عددية

حاصل ضرب مقداري المتجهين في جيب تمام الزاوية بينهما.

A⃗ · B⃗ = |A||B| cosθ

A⃗ · B⃗ = AₓBₓ + AᵧBᵧ + A_zB_z
خاصية مهمة: إذا كان A⃗ · B⃗ = 0 فإن المتجهين متعامدان (θ=90°).
î·î = ĵ·ĵ = k̂·k̂ = 1   |   î·ĵ = ĵ·k̂ = î·k̂ = 0

② الضرب الاتجاهي (Cross Product) → نتيجته متجه

مقداره = حاصل ضرب المقدارين × جيب الزاوية، واتجاهه عمودي على المستوى المحتوي لهما.

A⃗ × B⃗ = |A||B| sinθ n̂

|A⃗ × B⃗| = |A||B| sinθ
î×ĵ = k̂  |  ĵ×k̂ = î  |  k̂×î = ĵ
ĵ×î = −k̂  |  î×î = 0  |  A⃗×B⃗ = −B⃗×A⃗
خاصية مهمة: إذا كان |A⃗ × B⃗| = 0 فإن المتجهين متوازيان (θ=0° أو 180°).

سؤال ١٣  |  Q-013 صعب · Hard
التسارع a لجسيم يدور في دائرة يتناسب مع r^n و v^m. استخدم التحليل البُعدي لإيجاد n و m.
Centripetal acceleration a ∝ rⁿ vᵐ. Use dimensional analysis to find n and m.
نفرض: a = k rⁿ vᵐ
الأبعاد: [a] = LT⁻²
[k rⁿ vᵐ] = Lⁿ (LT⁻¹)ᵐ = L^(n+m) T^(-m)

مطابقة الأبعاد:
للزمن T: -2 = -m ⟹ m = 2
للطول L: 1 = n+m = n+2 ⟹ n = -1

∴ a = k r⁻¹ v² = kv²/r
(هذه معادلة التسارع المركزي المعروفة!)
n = -1, m = 2 → a = v²/r (centripetal acceleration)
سؤال ١٤  |  Q-014 صعب · Hard
أثبت باستخدام التحليل البعدي أن ثابت الجاذبية G في F = Gm₁m₂/r² له بُعد [M⁻¹L³T⁻²].
Prove that gravitational constant G has dimension [M⁻¹L³T⁻²].
من قانون الجاذبية: F = G m₁m₂/r²
نعزل G: G = F r² / (m₁ m₂)

[G] = [F][r²] / [m₁][m₂]
[G] = (MLT⁻²)(L²) / (M)(M)
[G] = ML³T⁻² / M²
[G] = M⁻¹L³T⁻² ✓
G = Fr²/m₁m₂ → [G] = M⁻¹L³T⁻²
سؤال ١٥  |  Q-015 صعب · Hard
البندول البسيط: فترته تعتمد على m (كتلة), l (طول), g (تسارع جاذبي). اشتق الصيغة P = k m^x l^y g^z.
Simple pendulum period P depends on mass m, length l, gravity g. Find x, y, z in P = k m^x l^y g^z.
[P] = T
[m^x l^y g^z] = M^x · L^y · (LT⁻²)^z = M^x · L^(y+z) · T^(-2z)

مطابقة الأبعاد مع T¹:
M: 0 = x ⟹ x = 0 (الكتلة لا تؤثر!)
T: 1 = -2z ⟹ z = -½
L: 0 = y+z = y - ½ ⟹ y = ½

∴ P = k √(l/g)
(والقيمة الحقيقية: k = 2π)
x=0, y=½, z=-½ → P = k√(l/g). Mass has NO effect!
سؤال ١٦  |  Q-016 صعب · Hard
معادلة موجية: y = A sin(kx - ωt). ما أبعاد k؟ وما العلاقة بين k و ω والسرعة الموجية v؟

[v] = T⁻¹ / L⁻¹ = LT⁻¹ ✓ (أي بُعد سرعة صحيح)
v = ω/k
[k] = L⁻¹ (wave number), v = ω/k (wave speed)
