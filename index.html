S1. اشتق الصيغة البعدية لـ Power (القدرة)

القدرة = شغل ÷ زمن = Force × distance / time
[Power] = [F][L]/[T] = [MLT⁻²][L]/[T]
[Power] = [ML²T⁻³] → وحدة SI: Watt (W)
Power = Work/Time = [ML²T⁻²]/[T] = [ML²T⁻³]

S2. اشتق بُعد معامل اللزوجة: η = F·d / (A·v)

[η] = [F][d] / ([A][v])
= [MLT⁻²][L] / [L²][LT⁻¹]
= [ML²T⁻²] / [L³T⁻¹]
[η] = [ML⁻¹T⁻¹] → وحدة: Pa·s
[η] = MLT⁻²·L / (L²·LT⁻¹) = ML⁻¹T⁻¹

S3. تحقق من صحة: v² = u² + 2as

يسار: [v²] = (LT⁻¹)² = L²T⁻²
يمين: [u²] = L²T⁻² ✓  |  [2as] = (LT⁻²)(L) = L²T⁻² ✓
جميع الحدود لها نفس البعد → المعادلة صحيحة بعدياً ✓
All terms = [L²T⁻²] ✓ Dimensionally correct.

S4. في معادلة Van der Waals: (P + a/V²)(V - b) = RT. أوجد أبعاد a وb.

إيجاد [a]: يُضاف a/V² للضغط P → لهما نفس البعد
[a/V²] = [P] → [a] = [P][V²] = [ML⁻¹T⁻²][L⁶] = [ML⁵T⁻²]

إيجاد [b]: يُطرح b من الحجم V → [b] = [V] = [L³]
[a] = ML⁵T⁻² | [b] = L³

S5. في: v = At + b/(t+c) أوجد أبعاد A و b و c.

[v] = [LT⁻¹]
[A]: [At] = [v] → [A][T] = LT⁻¹ → [A] = LT⁻² (تسارع)
[c]: يُضاف لـ t → [c] = [T]
[b]: [b/(t+c)] = [v] → [b]/[T] = LT⁻¹ → [b] = L
[A]=LT⁻², [b]=L, [c]=T

📐 العمليات على المتجهات

Vector operations — addition, dot product, cross product

① جمع المتجهات (Triangle / Parallelogram Law)

R = √(A²+B²+2AB cosθ)  |  tanβ = B sinθ/(A+B cosθ)

② الضرب النقطي — Dot Product (ناتجه عددي)

A⃗·B⃗ = |A||B|cosθ = AₓBₓ+AᵧBᵧ+A_zB_z
A⃗·B⃗=0 → متعامدان (θ=90°)  |  î·î=1, î·ĵ=0

③ الضرب الاتجاهي — Cross Product (ناتجه متجه)

|A⃗×B⃗| = |A||B|sinθ  |  î×ĵ=k̂, ĵ×k̂=î, k̂×î=ĵ
|A⃗×B⃗|=0 → متوازيان (θ=0° أو 180°)

Laws of circular motion — centripetal force & acceleration

aᶜ = v²/r = ω²r  |  Fᶜ = mv²/r = mω²r
ω = 2πf = 2π/T  |  v = ωr
القوة المركزية (Centripetal): دائماً نحو المركز، عمودية على السرعة.
القوة الطاردة المركزية (Centrifugal): قوة وهمية (خيالية) — تظهر فقط في الإطار المتسارع.

📖 مسائل الكراسة — Workbook Problems

C1. كرة في دائرة نصف قطرها 60 cm بمعدل 1 دورة كل 2s. أوجد التسارع المركزي.

T=2s, r=0.60m
ω = 2π/T = 2π/2 = π rad/s
aᶜ = ω²r = π²×0.60 ≈ 9.87×0.60 ≈ 5.92 m/s²
aᶜ=ω²r=π²×0.6≈5.92 m/s²

C2. حجر على خيط 0.5m يدور في دائرة رأسية بسرعة 5 m/s. الشد في الخيط أسفل الدائرة؟

عند الأسفل (الجاذبية والشد في اتجاهين متعاكسين):
T - mg = mv²/r
T = m(g + v²/r) = 1×(9.8 + 25/0.5) = 1×(9.8+50) = 59.8 N

عند الأعلى: T + mg = mv²/r
T = m(v²/r - g) = 1×(50-9.8) = 40.2 N
Bottom: T=m(g+v²/r)=59.8N | Top: T=m(v²/r-g)=40.2N

C3. ماهي قوة الجاذبية بين كرتين رصاص كل منهما 1000 kg على بُعد 3m؟

F = Gm₁m₂/r² = (6.67×10⁻¹¹)(10³)(10³)/(3)²
= 6.67×10⁻¹¹×10⁶/9 = 7.4×10⁻⁵ N
F=6.67×10⁻¹¹×10⁶/9=7.4×10⁻⁵N (very small!)

Work, power and energy laws

W = F·d·cosθ  |  P = W/t = F·v
KE = ½mv²  |  PE = mgh  |  PE_spring = ½kx²
E_total = KE + PE = constant (حفظ الطاقة)
مبدأ حفظ الطاقة: الطاقة لا تُفقد ولا تُخلق من العدم — تتحول من صورة لأخرى.

📖 مسائل الكراسة

W1. شدّ حجر 10m أفقياً بحبل يميل 30° عن الأرض بقوة 50N. أوجد الشغل.

W=50×10×cos30°=433J

W2. زنبرك ممدد 20mm طاقته الوضعية 10J. ما طاقته عندما يُمدد 30mm؟

PE = ½kx² → 10 = ½k(0.02)² → k = 10/(0.0002) = 50000 N/m
PE_new = ½×50000×(0.03)² = ½×50000×0.0009 = 22.5 J
PE∝x² → PE_new=10×(30/20)²=10×2.25=22.5J

W3. شخص وزنه 65kg يرفع 45kg ارتفاع 10m في 12s. الشغل الكلي والقدرة؟

الكتلة الكلية = 65+45 = 110 kg
W = mgh = 110×9.81×10 = 10791 J ≈ 10.8 kJ
P = W/t = 10791/12 ≈ 899 W ≈ 0.9 kW
W=10791J | P=899W
